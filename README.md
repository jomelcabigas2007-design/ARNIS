# Arnis Scoreboard

This is a static HTML scoreboard that is ready to be uploaded to GitHub and published via GitHub Pages.

## Files
- `index.html` — main scoreboard page
- `assets/logos/` — college logo placeholders used by the scoreboard

## Notes
- All asset paths are relative so the page works on GitHub Pages.
- Replace the placeholder SVG logo files in `assets/logos/` with the official college logos if needed.
- Open the page in a browser after pushing to GitHub.
